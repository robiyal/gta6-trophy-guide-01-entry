Leonida Trophy Guide — an offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy with its official name, description and grade, a guide in its own words with cited sources, a roadmap to the platinum, missable warnings, a spoiler setting, and a checklist saved in the browser with export and import. No network needed: static files only.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
